# Deep Notes – skratky pre Check (zaužívané anatomické skratky)
# skratka = plné slovo        (viac možností oddeľ čiarkou)
# Bodka nevadí: "lig." = "lig". Stačí jeden tvar slova: "ant" platí pre anterior aj anterius.
# Začiatok slova funguje vždy aj bez slovníka (pr, sulc, transv …) – slovník je hlavne
# pre skratky, ktoré nie sú začiatkom slova (tuberc → tuberculum je začiatok, ale napr. ligg nie).
# Tá istá skratka môže byť aj viackrát – platí každý význam.
# Riadky s # sú poznámky. Zmeny platia od ďalšej karty, netreba reštart.
