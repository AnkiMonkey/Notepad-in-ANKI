AnkiMonkey – user_files (Anki keeps this folder when the add-on is updated)
=========================================================================
PRIVATE – never share this folder. It holds your own data:

templates/              Deep Notes TXT templates (File name = tag or deck, "::" -> "__")
                        Examples: templates/_example_*.txt
legend_*.json           Deep Notes legends (Auto rows + Check), made from your cards
abbreviations.txt       Deep Notes abbreviations (tbc = tuberculum ...)
backup_media/           Deep Notes backup copies of legend images
prompts/                Ask prompts (TXT). latinsky_slovnik.txt = Latin dictionary
claude_cwd/             empty working folder for Claude Code (keeps it away from your files)
models/                 Whisper speech model (~3 GB, downloaded once)
error.log               errors of all modules
