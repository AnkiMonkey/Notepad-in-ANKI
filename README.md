# Voice libraries for AnkiMonkey

Python libraries for the **Voice** module (faster-whisper 1.2.1, ctranslate2 4.8.4, numpy 2.5.4, sounddevice 0.5.6, onnxruntime 1.31.1, tokenizers 0.23.3 …), built from the official PyPI wheels for **Windows x64 + Python 3.13**.

The add-on downloads the `vendor-win64-py313.zip.part*` files by itself the first time you switch 🎤 ON, joins them and checks the SHA-256 in `SHA256`. You never need to touch this branch.
